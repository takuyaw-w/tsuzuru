# v0.6.0 Plan: ScreenHost

> Status: historical/planned note from before the DSL v2 cleanup. References to
> removed examples are not current guidance.

## Status

Planned.

## Purpose

v0.6.0 adds a custom screen UI foundation to `@tsuzuru/standard-ui-preact`.

The main implementation target is a new `ScreenHost` component.

v0.6.0 does not add DSL, core, or runtime integration. The goal is to let users create custom screen components in TypeScript / Preact and pass them to `ScreenHost` as an app-local registry.

v0.7.0 will revisit DSL / runtime integration. v0.8.0 will revisit `create-tsuzuru` starter template integration.

## Planned Public API

```ts
export type ScreenComponentProps<TParams = unknown> = {
  readonly params: TParams | undefined;
  readonly onClose: () => void;
};

export type ScreenComponent<TParams = unknown> = (
  props: ScreenComponentProps<TParams>,
) => ComponentChildren;

export type ActiveScreen<TParams = unknown> = {
  readonly id: string;
  readonly params?: TParams;
};

export type ScreenRegistry = Record<string, ScreenComponent>;

export type ScreenHostProps = {
  readonly activeScreen: ActiveScreen | null;
  readonly screens: ScreenRegistry;
  readonly onClose: () => void;
  readonly className?: string;
};
```

## Planned Usage

```tsx
const [activeScreen, setActiveScreen] = useState<ActiveScreen | null>(null);

const screens = {
  notebook: NotebookScreen,
} satisfies ScreenRegistry;

<ScreenHost
  activeScreen={activeScreen}
  screens={screens}
  onClose={() => setActiveScreen(null)}
/>;
```

## Expected Behavior

- `activeScreen === null` の場合は `null` を render する
- `activeScreen.id` に対応する screen component が `screens` に存在する場合、その screen を render する
- registered screen component には `params` と `onClose` を渡す
- `activeScreen.id` に対応する screen component が存在しない場合は fallback UI を render する
- fallback UI には close button を表示し、`onClose` できるようにする
- `className` は outer wrapper に適用する
