# Tsuzuru v0.1.0

Initial npm release of Tsuzuru.

## Highlights

- DSL v2 parser, compiler, and runtime in `@tsuzuru/core`.
- Include-based multi-file scenario compilation for `.tzr` projects.
- Project configuration helpers in `@tsuzuru/config`.
- CLI package `@tsuzuru/cli` with `tsuzuru check`.
- Project generator package `create-tsuzuru`.
- Standard visual and audio plugins.
- Preact runtime adapter in `@tsuzuru/preact`.
- Standard UI Preact components in `@tsuzuru/standard-ui-preact`.
- Basic create-tsuzuru template with TSX screens.

## Packages

- `@tsuzuru/core`
- `@tsuzuru/config`
- `@tsuzuru/cli`
- `@tsuzuru/preact`
- `@tsuzuru/standard-ui-preact`
- `@tsuzuru/plugin-std-visual`
- `@tsuzuru/plugin-std-audio`
- `create-tsuzuru`

## Current Limitations

- Save/load storage is not fully implemented.
- Gallery, backlog, and settings screens are placeholders.
- `create-tsuzuru` supports only the basic template.
- No Vite plugin yet.
- No `tsuzuru dev` or `tsuzuru build` command yet.
- Generated project install works only after npm packages are published.
- Multi-file scenarios are compiled through includes into one project-level
  scene set; scene names must remain unique.
