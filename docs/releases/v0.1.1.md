# Tsuzuru v0.1.1

Replacement npm release for v0.1.0.

## Highlights

- Reissues the initial Tsuzuru package set as `v0.1.1`.
- Keeps internal workspace development dependencies on `workspace:^`.
- Updates the `create-tsuzuru` basic template to install `@tsuzuru/*`
  packages from `^0.1.1`.

## Packages

- `@tsuzuru/core`
- `@tsuzuru/config`
- `@tsuzuru/cli`
- `@tsuzuru/preact`
- `@tsuzuru/standard-ui-preact`
- `@tsuzuru/plugin-std-visual`
- `@tsuzuru/plugin-std-audio`
- `create-tsuzuru`

## Publish Notes

- v0.1.0 was unpublished due to broken workspace dependency metadata.
- Publish from the pnpm workspace with `pnpm --filter <package> publish`.
- Do not use direct package-path npm commands such as
  `npm publish ./packages/core`; they do not perform pnpm workspace protocol
  conversion.
- Use `pnpm --filter <package> publish --dry-run` before the real publish when
  checking that `workspace:^` dependencies convert to publishable semver ranges.
- Do not create `git tag v0.1.1` or a GitHub release until publish readiness is
  confirmed.

## Current Limitations

- Save/load storage is not fully implemented.
- Gallery, backlog, and settings screens are placeholders.
- `create-tsuzuru` supports only the basic template.
- No Vite plugin yet.
- No `tsuzuru dev` or `tsuzuru build` command yet.
- Multi-file scenarios are compiled through includes into one project-level
  scene set; scene names must remain unique.
