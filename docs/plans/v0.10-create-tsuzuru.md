# v0.10 create-tsuzuru Plan

Status: minimal package, basic/Preact template, and HTML template selection.

`create-tsuzuru` provides the first local project generator for future
`pnpm create tsuzuru my-game` and `npm create tsuzuru@latest my-game` flows.

Implemented scope:

- The bundled `basic` template remains the default.
- `preact` is accepted as an alias for the existing `basic` template.
- `html` selects the framework-free `@tsuzuru/html` template.
- Templates live inside `packages/create-tsuzuru/templates`, not under
  `examples`.
- Generated projects include `tsuzuru.config.ts`.
- Generated projects run `tsuzuru check` from `check:scenario` and before
  `vite build`.
- The CLI accepts `create-tsuzuru <project-name> [--template basic|preact|html]`.

The basic template mirrors the current `examples/preact-basic` shape while
staying publishable as part of the create package. Title, settings, load,
backlog, and gallery are TSX screens. `.tzr` files remain focused on scenario
content, branching, and presentation commands after game start.

Deferred work:

- interactive UI
- automatic dependency installation
- package manager detection
- git initialization
- remote template downloads
- overwrite support
- `--pm` and `--yes`
- Vite plugin integration
- `tsuzuru dev` and `tsuzuru build`
