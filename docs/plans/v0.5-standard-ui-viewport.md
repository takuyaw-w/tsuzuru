# v0.5.0 Plan: Standard UI Viewport

> Status: historical/planned note from before the DSL v2 cleanup. References to
> removed examples are not current guidance.

## Status

Planned.

## Purpose

v0.5.0 adds viewport and aspect-ratio support to `@tsuzuru/standard-ui-preact`.

The main implementation target is a new `GameViewport` component.

## Scope

### Included

- Add `GameViewport` to `@tsuzuru/standard-ui-preact`
- Support fixed aspect ratios:
  - `16:9`
  - `4:3`
- Support optional `maxWidth`
- Add viewport CSS classes
- Update `GameShell` CSS to fit inside the provided viewport
- Update `examples/standard-ui-preact` to use `GameViewport`
- Run tests and typecheck

### Excluded

- `fit` prop
- `maxHeight` prop
- safe area support
- screen registry
- custom screen system
- notebook / evidence screen
- config screen
- save/load screen
- theme system
- create-tsuzuru changes
- release work
- v0.5.0 tag creation

## Planned Public API

```ts
export type GameViewportAspectRatio = "16:9" | "4:3";

export type GameViewportProps = {
  aspectRatio?: GameViewportAspectRatio;
  maxWidth?: number | string;
  className?: string;
  style?: JSX.CSSProperties;
  children: ComponentChildren;
};
```

## Planned Usage

```tsx
<GameViewport aspectRatio="16:9" maxWidth={960}>
  <GameShell>
    ...
  </GameShell>
</GameViewport>
```

Minimal usage:

```tsx
<GameViewport>
  <GameShell>
    ...
  </GameShell>
</GameViewport>
```

Default behavior:

- `aspectRatio`: `"16:9"`
- `maxWidth`: not set
- layout behavior: contain-only

## Implementation Tasks

### 1. Add `GameViewport`

Create:

```txt
packages/standard-ui-preact/src/game-viewport.tsx
```

Implement:

- `GameViewport`
- `GameViewportProps`
- `GameViewportAspectRatio`
- aspect ratio resolution
- max width resolution
- outer `className` support
- outer `style` support
- two-layer DOM structure

Expected DOM structure:

```tsx
<div className="tzr-game-viewport">
  <div className="tzr-game-viewport__inner">
    {children}
  </div>
</div>
```

### 2. Add Public Exports

Update:

```txt
packages/standard-ui-preact/src/index.ts
```

Add:

```ts
export { GameViewport } from "./game-viewport";
export type {
  GameViewportAspectRatio,
  GameViewportProps,
} from "./game-viewport";
```

### 3. Update CSS

Update:

```txt
packages/standard-ui-preact/src/style.css
```

Add:

```css
.tzr-game-viewport {
  width: 100%;
  margin-inline: auto;
}

.tzr-game-viewport__inner {
  width: 100%;
  height: 100%;
  overflow: hidden;
}
```

Update `.tzr-game-shell` so it fills the provided viewport.

Expected direction:

```css
.tzr-game-shell {
  width: 100%;
  height: 100%;
}
```

Do not keep full-screen-oriented sizing such as `min-height: 100vh` if it conflicts with `GameViewport`.

### 4. Update Example

Update:


The example should wrap `GameShell` with `GameViewport`.

Expected usage:

```tsx

  </GameShell>

```

The example should explicitly pass `aspectRatio="16:9"` even though it is the default.

## Acceptance Criteria

- `GameViewport` is exported from `@tsuzuru/standard-ui-preact`.
- `GameViewportProps` is exported.
- `GameViewportAspectRatio` is exported.
- `aspectRatio` supports `"16:9"` and `"4:3"`.
- `aspectRatio` defaults to `"16:9"`.
- `maxWidth={960}` resolves to `"960px"`.
- `maxWidth="80vw"` is passed through as `"80vw"`.
- `className` is applied to the outer wrapper.
- `style` is applied to the outer wrapper.
- Internal calculated `aspectRatio` and `maxWidth` override conflicting values from `style`.
- `.tzr-game-viewport` is defined.
- `.tzr-game-viewport__inner` is defined.
- `.tzr-game-viewport__inner` has `overflow: hidden`.
- `.tzr-game-shell` fills the viewport with `height: 100%`.
- `examples/standard-ui-preact` uses `GameViewport`.
- No `fit` prop is added.
- No `maxHeight` prop is added.
- No safe area API is added.
- No custom screen system is added.
- No viewport plugin package is added.
