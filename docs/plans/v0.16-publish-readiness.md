# v0.16 Publish Readiness Plan

Status: draft execution checklist.

This checklist prepares Tsuzuru packages for npm publishing. It does not publish,
tag, bump versions, or create GitHub releases.

## Publish Targets

Publishable packages:

- `packages/core` publishes as `@tsuzuru/core`
- `packages/config` publishes as `@tsuzuru/config`
- `packages/cli` publishes as `@tsuzuru/cli`
- `packages/preact` publishes as `@tsuzuru/preact`
- `packages/standard-ui-preact` publishes as `@tsuzuru/standard-ui-preact`
- `packages/plugin-std-visual` publishes as `@tsuzuru/plugin-std-visual`
- `packages/plugin-std-audio` publishes as `@tsuzuru/plugin-std-audio`
- `packages/create-tsuzuru` publishes as `create-tsuzuru`

Publish excluded:

- root `tsuzuru` package, which must stay `private: true`
- `examples/dsl-v2-basic`
- docs, plans, tests, and repository-only tooling

## npm Assumptions

- Scoped packages publish under the `@tsuzuru` npm org.
- Scoped packages require public access, so each `@tsuzuru/*` package should set
  `publishConfig.access` to `public`.
- `create-tsuzuru` is unscoped, so it does not need `publishConfig.access`.
- Package names and npm org ownership must be confirmed before publish.
- The repository uses the MIT License, and publishable packages declare
  `"license": "MIT"`.

## Pack Dry-Run

Run from the repository root after dependencies are installed and packages are
built:

```sh
pnpm --filter @tsuzuru/core pack --dry-run
pnpm --filter @tsuzuru/config pack --dry-run
pnpm --filter @tsuzuru/cli pack --dry-run
pnpm --filter @tsuzuru/preact pack --dry-run
pnpm --filter @tsuzuru/standard-ui-preact pack --dry-run
pnpm --filter @tsuzuru/plugin-std-visual pack --dry-run
pnpm --filter @tsuzuru/plugin-std-audio pack --dry-run
pnpm --filter create-tsuzuru pack --dry-run
```

Equivalent root helper:

```sh
pnpm run pack:dry-run
```

Confirm each package includes:

- `package.json`
- `README.md`
- compiled JavaScript and `.d.ts` files under the exported paths
- CLI `bin` targets for `@tsuzuru/cli` and `create-tsuzuru`
- `@tsuzuru/standard-ui-preact/style.css`
- `create-tsuzuru` `templates/basic/**`, including asset `.gitkeep` files

Confirm each package excludes:

- repository docs and plans
- tests
- unrelated examples
- source-only files that are not part of the public package

## Required Checks

Prefer `rtk` when available:

```sh
rtk pnpm install --frozen-lockfile
rtk pnpm format:check
rtk pnpm lint
rtk pnpm check
rtk pnpm test
rtk pnpm run typecheck
rtk pnpm --filter @tsuzuru/example-dsl-v2-basic build
rtk git diff --check
```

Also run the pack dry-run commands above after the full checks.

## Known Blockers

- Confirm npm login and npm org `@tsuzuru` publish permission.
- Generated projects from `create-tsuzuru` use semver Tsuzuru dependencies.
  Those installs can fail until the matching package versions are published.
- Version bump, git tag, and release notes are separate tasks.
- Provenance configuration and the actual publish command are separate tasks.
