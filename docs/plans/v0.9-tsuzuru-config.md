# v0.9 Tsuzuru Config Plan

Status: initial package and example config added.

`@tsuzuru/config` provides `defineTsuzuruConfig()` and the minimal config types
needed for future tooling. The first supported config shape is:

```ts
defineTsuzuruConfig({
  scenario: {
    entry: "scenario/main.tzr",
    files: ["scenario/**/*.tzr"],
  },
  plugins: [createStdVisualPlugin(), createStdAudioPlugin()],
});
```

Planned follow-up work:

- load `tsuzuru.config.ts` from tooling
- resolve defaults and validate config
- expand `scenario.files` patterns outside core
- connect the config to future create-tsuzuru templates
- consider Vite integration without making `.tzr` glob patterns dynamic inside
  application code

Current constraints:

- Core does not read the file system.
- The example still uses `src/scenario.ts` and Vite `import.meta.glob` as the
  runtime adapter.
- `tsuzuru.config.ts` is not auto-discovered yet.
- Title, load, settings, backlog, and gallery are still TSX / HTML host code.
- `.tzr` remains focused on scenario content after Start.
