# v0.12 Standard UI Hooks Plan

Status: phase 1 implemented for `@tsuzuru/standard-ui-preact`.

## Goal

Move reusable runtime UI helper logic out of `examples/preact-basic` when the
logic is package-safe and does not encode host application policy.

## Phase 1 Scope

- `useAutoMode`
- `useMessageHistory`

`useAutoMode` owns only local enabled state and delayed advancement while the
host says advancement is allowed. It does not know about runtime documents,
storage, scenario identity, read tracking, or skip policy.

`useMessageHistory` owns only narration/dialogue history collection for runtime
events and duplicate suppression by host-provided `eventKey`. It does not store
history persistently, compute read/unread state, or render backlog UI.

## Host-Owned Policy

The example keeps the following responsibilities in application code:

- storage keys and persistence backend
- scenario identity validation
- Read Tracking persistence
- Skip Mode behavior
- backlog read/unread mapping
- save/load overlays and retained messages
- user preferences

Package hooks should stay policy-free so generated projects and host
applications can choose their own storage namespace, read identity, and
presentation behavior.

## Deferred Work

`useReadTracking` remains deferred until stable read identity, configuration
surface, and storage namespace policy are designed. Skip Mode and storage helper
package extraction are also outside this phase.
